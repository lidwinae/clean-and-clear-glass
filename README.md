# Clean and Clear Glass - NeoForge 1.21.1

A standalone client-side NeoForge mod that provides clean, clear,
and connected rendering for vanilla glass blocks and glass panes.

This version uses NeoForge's 1.21.1 BakedModel and ModelData systems
to read neighboring glass blocks and generate the appropriate
connected geometry.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.244
- Java 21

No additional rendering API, CTM mod, or resource pack is required.
Sodium and Iris are optional.
