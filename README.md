# Clean and Clear Glass - NeoForge 26.3

Clean and Clear Glass is a standalone client-side NeoForge mod that provides clean, clear, and connected rendering for vanilla glass blocks and glass panes.

## How it works

The mod replaces the baked client-side geometry of vanilla glass while keeping the original vanilla blocks and items.

Matching glass blocks hide connected internal borders. Glass panes use connection-aware geometry, vertical seam handling, endpoint caps, and visible T/cross intersections.

Regular glass provides Clear and Subtle styles. Tinted glass provides Subtle, Visible, and Clear styles.

Item models are selected conditionally. When Clean and Clear Glass is disabled, vanilla item and block rendering is restored.

## Requirements

- Minecraft 26.3
- NeoForge 26.3.0.1-beta or newer for Minecraft 26.3
- Java 25
